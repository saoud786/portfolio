# 🌐 Personal Portfolio - Saoud Ali

A modern and responsive personal portfolio website built using React.  
Showcases projects, skills, and contact details with a clean UI/UX.

---

## 🔥 Features

- ⚡ Fully responsive design (Mobile + Desktop)
- 🎨 Light & Dark theme toggle
- 📂 Project showcase section
- 📧 Contact form with EmailJS integration
- 📋 Copy-to-clipboard functionality (Email & Phone)
- ✨ Smooth animations and modern UI
- 🧑‍💻 Clean and structured code

---

## 🛠️ Tech Stack

- React.js
- CSS3
- JavaScript (ES6+)
- EmailJS
- Vite
